## Major changes

- engineering asset model above raw hardware endpoints
- USB + serial interface resolution into one physical asset when evidence is strong
- identity confidence and evidence trail
- persistent local asset registry
- device capabilities and documentation targets
- persistent diagnostic-session memory
- asset-aware voice events and commands
- cloud reasoning receives resolved asset context
- batched registry writes to protect low-end Mac performance
